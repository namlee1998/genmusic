# Component Inventory

| Component | Mô tả | Trạng thái | Tái sử dụng |
|---|---|---|---|
| `GoogleSignInButton` | Nút "Sign in with Google" theo brand guideline | default / hover / loading / disabled | Mới |
| `AuthDivider` | Dải phân cách "hoặc" giữa form và nút social | default | Mới |
| `ErrorBanner` | Banner thông báo lỗi xác thực phía trên form | hidden / visible | Tái dùng |
| `LoginForm` | Form email/mật khẩu hiện có | default / error | Có sẵn |
| `Spinner` | Spinner nhỏ trong nút khi loading | spinning | Có sẵn |
